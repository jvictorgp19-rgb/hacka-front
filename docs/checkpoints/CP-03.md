# CP-03 — Demo sem backend

Status: concluído. Base anterior: `2b386c5`.

Rota POST /api/chat e src/lib/api.ts retirados somente depois de provar o chat via
provider no navegador. Adaptador temporário mantém componentes antigos funcionais.
Cenários, catálogo (14 versões), quatro marcos do radar e auditoria cadastrada
foram preservados em fixtures. Doze evidências possuem trecho e página conferidos
via extração do PDF sintético; não existe ingestão, RAG ou LLM no provider.

Demo possui armazenamento versionado segregado por persona e reset da própria chave.
Consulta desconhecida resulta em abstenção. Retiradas métricas fictícias de custo,
placar 100% e mensagens de envio real nas ações locais.

Validação: 14 testes unitários; lint, tipos e build estático aprovados. Dois testes
Chromium passaram contra out servido por Python HTTP, sem servidor Next/FastAPI.
A consulta demo não fez requisição para /api/chat ou porta 8000.
Exportação com output:export/trailingSlash; cacheComponents/partialPrefetching
retirados, pois não são necessários para esta aplicação cliente exportada.

Limites: no modo API, a tela antiga baseada em JSON fica bloqueada por diagnóstico
de conexão até a composição comum do CP-04. Contratos externos continuam propostos.
Não há comprovação de backend real, segurança, auditoria durável ou envio de e-mail.
