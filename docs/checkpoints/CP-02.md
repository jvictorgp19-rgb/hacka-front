# CP-02 — Gateway e contrato proposto

Status: concluído. Base anterior: `5f8d707`.

AppGateway define catálogo, evidências, consultas, radar, curadoria, arquivos,
histórico, feedback e identidade. DTOs Zod validam respostas e referências de fonte.
Provider HTTP usa timeout, cancelamento e erros explícitos, com limpeza de listeners.
Radar existente já consome o gateway HTTP quando configurado no modo API.
As demais funções antigas continuam isoladas até o CP-03; a API local ainda existe.

Validação: nove testes unitários aprovados, incluindo 401/403/500, resposta inválida,
catálogo válido, timeout e cancelamento; lint e tipos aprovados.
Contrato completo e limites em `docs/API-CONTRACT.md`. Zod adicionado por validação
runtime, não apenas tipos apagados no build. Dependências principais preservadas.

Limites: paths são propostos e não comprovam implementação no FastAPI; autenticação,
paginação e processamento assíncrono precisam de alinhamento com o outro repo.
