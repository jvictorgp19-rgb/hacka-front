# IB-04 — Decisão e original

Aprovar/recusar no Acervo atual, com botões e diálogo existentes. Recusa exige motivo;
ação vinculada a canApprove do item, lock contra reenvio e confirmação somente após
resposta válida. 403/404/409/503 são explícitos, com atualização da fila. Original
via Blob/contexto de identidade, nome sanitizado e object URL liberada. HTTP 200
com JSON/HTML não vira arquivo. Status técnico e decisão de negócio permanecem distintos.

16 E2E API controlados aprovados (incluindo aprovação, download, recusa, falhas e
resposta de histórico atrasada); 49 unitários com validação do header de persona e
download inválido. Integração real será registrada separadamente em IB-05.
