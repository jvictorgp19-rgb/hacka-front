## Ajustes encontrados na homologação

Cancelamento precisava impedir o default do formulário ao trocar o botão para Enviar.
Botões agora têm tipos/chaves distintos e cancelar encerra imediatamente o estado de
espera; retornos de requisições antigas não alteram a conversa. O teste confirma uma
única chamada e espera a resposta tardia antes de verificar o descarte.

Identidade/capacidades são obtidas antes de solicitar alertas restritos. Snapshot
inexistente não é substituído pela seleção atual. Upload preserva ID remoto e permite
atualização explícita; JSON malformado e URL de fonte inválida são erros de contrato.

A formatação sem mudança funcional foi separada do fechamento deste checkpoint.

## Limites e handoff

Os E2E API usam fixtures de contrato, não um FastAPI real. Autenticação, autorização,
NeonDB, ingestão/OCR/RAG, calendário corporativo completo, auditoria durável, e-mail e
PPTX continuam externos. Demo não interpreta PDF novo nem reivindica precisão universal.
Nenhum recurso AWS foi provisionado. `FRONTEND-HANDOFF.md` explica exportação,
configuração de build e requisitos de CloudFront/S3, incluindo acesso direto às rotas.

Desenvolvimento permanece em Dev; Homolog/main recebem promoção após revisão.
