# Marcas locais

- `bbts-wordmark.png`: arquivo transparente original da BBTS, obtido em 13/11/2026:
  https://www.bbts.com.br/wp-content/uploads/2025/05/BB_Tecnologia_e_Servicos-amarelo.png
  A geometria e as proporções permanecem intactas. A interface usa a máscara alfa
  para aplicar azul em superfícies claras e amarelo em superfícies escuras/azuis,
  conforme a referência enviada. Na navegação recolhida, o viewport mostra apenas
  o símbolo à esquerda; o arquivo original não é recortado nem alterado.
- `zero-click-symbol.svg`: cópia integral do SVG `simbolo_cursor_proibido.svg`
  fornecido pelo usuário. A máscara CSS preserva o desenho e acompanha a cor da
  superfície. O arquivo original amarelo permanece intacto.

As marcas não dependem de carregamento remoto. Símbolos junto ao nome são decorativos;
a assinatura BBTS tem nome acessível e o link da solução anuncia seu destino.
